# Palindrome Checker App

## 📌 Project Overview
The **Palindrome Checker App** is a console-based Java application designed to validate whether a given string is a palindrome under different conditions.

This project strengthens core Java programming fundamentals and basic data structure concepts.

---

## 🎯 Objective
To implement multiple use cases for checking palindromes while demonstrating:
- String handling
- Character arrays
- Loops
- Conditional statements
- Two-pointer technique
- Time complexity awareness

---

## 🧩 Use Cases Implemented

### ✅ UC2: Hardcoded Palindrome Check
- Uses a predefined string.
- Reverses and compares the string.
- Displays whether it is a palindrome.

### ✅ UC3: Palindrome Check Using String Reverse
- Takes user input.
- Reverses the string using a `for` loop.
- Compares using `equals()` method.
- Demonstrates **String immutability** and concatenation.

### ✅ UC4: Character Array Based Palindrome Check
- Converts string into `char[]`.
- Uses **two-pointer technique**.
- Efficient comparison without creating extra objects.
- Time Complexity: **O(n)**
